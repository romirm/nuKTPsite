`countries.json` contains Natural Earth 1:110m country boundaries, reduced to country names and geometry. Source: the [globe.gl example dataset](https://github.com/vasturiano/globe.gl/blob/master/example/datasets/ne_110m_admin_0_countries.geojson). [Natural Earth data is public domain](https://www.naturalearthdata.com/about/terms-of-use/).

The geography is bundled so the member globe does not depend on a third-party map request.
